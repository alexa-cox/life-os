# Life OS

A personal operating system, built in Notion and run with an AI assistant. This repo is the home base for every part of it. Each article in the series links here, and everything here links back to the articles.

I'm Alexa, an aspiring data analyst. I treat my own life like a small data project: define what counts, build a first version, and refine it against real use.

## What's in here

| Folder | What it is | Status |
|---|---|---|
| [`morning-brief/`](morning-brief/) | A skeleton for a daily AI-generated morning brief: email triage, task picks, a Monday networking nudge, and a Saturday week plan | Available |
| `inbox/` | The "decide before you open" approach to starting the day | Planned |
| `job-fit-pipeline/` | An automated pipeline that scrapes, filters, deduplicates, and scores job postings | Planned |
| `notion-second-brain/` | The one rule I follow for keeping data in one place | Planned |

## How to use this repo

Start with the article that interests you, then come here for the templates. Everything in this repo is a skeleton. Replace the placeholders with your own sources, rules, and preferences. Nothing here contains personal data, and yours shouldn't end up in it either.

## A note on honesty

These are my own setups, shared as starting points. They work for me. They may not work for you without changes, and some parts have known limits, which each folder describes.
